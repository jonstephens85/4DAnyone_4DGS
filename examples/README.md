# Example action video

`action.mp4` is the personal action clip contributed by Jonathan Stephens for
this fork's reproducible examples (formerly `IMG_7164_linux_compatible.mp4`).
It is about 3.7 MB. The repository's Apache-2.0 license applies unless otherwise
noted. Attribution: Jonathan Stephens, 4DAnyone_4DGS example capture.

Start with [the example workflow](../docs/example.md). Generated videos,
reconstruction datasets and model checkpoints are not included; the commands
create them locally. To use your own capture, replace the video path and use its
filename without `.mp4` as the clip name in subsequent commands.
