# Install the 4DGS interactive viewer

Use **SIBR_remoteGaussian_app**, not the standalone static PLY viewer. The
[4DGS guide](4dgs.md#view-interactively) starts its Python rendering server.

## Linux desktop

Install build prerequisites, then clone the viewer source (do not assume a
separate Gaussian Splatting checkout is already installed):

```bash
sudo apt install -y build-essential cmake git libglew-dev libassimp-dev \
  libboost-all-dev libgtk-3-dev libopencv-dev libglfw3-dev libavdevice-dev \
  libavcodec-dev libeigen3-dev libxxf86vm-dev libembree-dev

git clone --recursive https://github.com/graphdeco-inria/gaussian-splatting work/gaussian-splatting
cmake -S work/gaussian-splatting/SIBR_viewers \
  -B work/gaussian-splatting/SIBR_viewers/build \
  -DCMAKE_BUILD_TYPE=Release -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build work/gaussian-splatting/SIBR_viewers/build -j4 --target install
```

The CMake policy flag accommodates older vendored dependencies when using CMake 4.
These are Linux build instructions; dependencies can differ by distribution.
If SIBR is already built elsewhere, use that executable instead.

With the server running, from the 4DAnyone fork's root:

```bash
work/gaussian-splatting/SIBR_viewers/install/bin/SIBR_remoteGaussian_app \
  --port 6019 --path "$PWD/outputs/4dgs/action-model"
```

## Windows client with a Linux server

Download the Windows viewer linked by the
[upstream viewer guide](https://github.com/hustvl/4DGaussians/blob/master/docs/viewer_usage.md).
Forward TCP port 6019 using VS Code's Ports panel or SSH. Copy the model directory's
`cameras.json` and `input.ply`, generated by `view_4dgs.py`, into a local model
folder for the client, then pass that folder as `--path`:

```powershell
.\viewers\bin\SIBR_remoteGaussian_app.exe --port 6019 --path C:\models\action-model
```

The model/deformation network stays on the Linux server. The server listens only
on localhost. The remote Windows arrangement is not tested by this fork; the
same-host Linux client was used for the documented experiment.

## Controls

In trackball mode, left-drag rotates, right-drag pans, and scrolling zooms.
Starting a drag near the border can roll or dolly. `Y` toggles trackball/FPS,
`B` orbit/FPS, `Space` snapping, and `P` snaps to a camera.
Animation time advances on the server; there is no time slider in this client.
Use the server's `--time` option for a fixed pose. Ctrl+C stops the server.
